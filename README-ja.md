# Comfy Sketch

**Language / 言語**: [🇺🇸 English](README.md) | [🇯🇵 日本語](README-ja.md)

Comfy Sketch は、ノートにペンで絵を描くような直感的な操作で下描きを作り、それを ComfyUI へ送って画像生成を行えるアプリケーションです。ペンタブやタッチスクリーンでスケッチし、ボタンひとつで ComfyUI ワークフローに組み込める――そんなクリエイター体験を目指しています。

## Motivation – なぜ作ったか

[ComfyUI]( https://github.com/comfyanonymous/ComfyUI ) は、ノードベースで高機能な画像生成アプリとして定評があります。
ノードベースなUIは柔軟でカスタマイズ性が高く、非常に素晴らしいアプリケーションです。

しかし、誰にとっても直感的なUIかというとそうではありません。多彩な設定ができる一方、絵を描いてきた人がノードを操作するにはハードルが高いことがあります。

ノートに絵を描くように画像生成を扱える体験こそ直感的であり、この体験を追求したいと考えたことがきっかけです。
