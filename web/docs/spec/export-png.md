# PNG エクスポート機能仕様書

## 概要

本仕様書は、描画キャンバスの内容をPNG画像としてエクスポートする機能について定義します。複数のレイヤーに分散した描画ライン（ペンストローク）を一つの画像に合成して出力します。

## 機能要件

### 1. エクスポート機能

- すべての表示レイヤーを単一のPNG画像としてエクスポート（非表示レイヤーは除外）
- レイヤーの合成順序とブレンドモードを維持
- レイヤーの不透明度（opacity）を適用
- 白背景でエクスポート（透明背景は非対応）

### 2. ユーザーインターフェース

- ツールバーにエクスポートボタンを追加
- ボタンをクリックすると即座にエクスポートを実行
- 成功/エラーのフィードバックをトースト通知で提供

### 3. エクスポート仕様

- **ファイル名**: 自動生成（"sketch-YYYYMMDD-HHMMSS.png"）
- **画像サイズ**: 現在のキャンバスサイズ（画面幅×画面高さ）
- **背景**: 白背景で固定
- **レイヤー**: 表示レイヤーのみ（非表示レイヤーは除外）

## 技術的実装

### 1. キャンバスレンダリング

- レンダリング用のオフスクリーンキャンバスを作成
- 白背景を適用（#FFFFFF）
- レイヤーをorder順にソートして処理
- 各レイヤーについて:
  - 非表示レイヤーはスキップ
  - レイヤーの不透明度（opacity）を適用
  - ブレンドモード（存在する場合）を適用
  - レイヤーに属する描画ライン（DrawingLine）をレンダリング
  - 消しゴムツールは「destination-out」で処理

### 2. エクスポートプロセス

```typescript
interface ExportOptions {
  filename: string;
  width: number;
  height: number;
  background: "white"; // 白背景で固定
  includeHiddenLayers: false; // 非表示レイヤーは含めない
}
```

### 3. ファイル生成

- `canvas.toBlob()`を使用してキャンバスをPNG形式のBlobに変換
- `URL.createObjectURL()`でダウンロード用URLを生成
- 非表示の`<a>`要素を作成してダウンロードをトリガー
- ダウンロード後にURLとDOM要素をクリーンアップ

### 4. パフォーマンスの考慮事項

- エクスポート処理中は進捗状態を内部で管理（0%→25%→75%→100%）
- 大きな画像のメモリ使用量に注意
- スケーリング機能を実装済み（現在は1:1でエクスポート）

## 実装手順

1. レイヤー合成ロジックを実装
2. UIにエクスポートボタンを追加
3. ボタンクリックで直接エクスポートを実行
4. ファイルダウンロードを処理
5. エラーハンドリングを実装
6. トースト通知でフィードバックを提供

## エラーハンドリング

- メモリ制限を処理
- エクスポート寸法を検証
- ブラウザのダウンロード制限を処理
- ユーザーに明確なエラーメッセージを提供

## ブラウザ互換性

- モダンブラウザとの互換性を確保
- ブラウザ固有の制限を処理
- 必要に応じて古いブラウザのフォールバックを提供

## 将来の拡張機能

- バッチエクスポート機能

- メタデータ付きエクスポート（レイヤー名、作成日）
